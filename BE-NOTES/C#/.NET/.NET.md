.NET è un ecosistema unificato per lo sviluppo di applicazioni: web, API, desktop, mobile, cloud, giochi. Dopo la frammentazione tra .NET Framework (Windows-only) e .NET Core (cross-platform), **.NET 5+** unifica tutto in un unico runtime, libreria base e toolchain.

## Architettura

```
Applicazione (ASP.NET Core, EF Core, MAUI, ...)
──────────────────────────────────────────────
Libreria Base (BCL) — System.*, collections, LINQ, I/O, HTTP
──────────────────────────────────────────────
Runtime .NET — GC, JIT (RyūJIT), ARM64/x64
──────────────────────────────────────────────
OS — Windows, Linux, macOS, container
```

Componenti chiave:
- **CLR** (Common Language Runtime) — esecuzione, GC, JIT, sicurezza
- **BCL** (Base Class Library) — collezioni, file, rete, crittografia
- **SDK** — compilatore (Roslyn), dotnet CLI, MSBuild

## dotnet CLI

### Comandi fondamentali

```bash
# Creare un progetto
dotnet new webapi -n MyApi
dotnet new console -n MyApp
dotnet new classlib -n MyLib

# Build, test, run
dotnet build
dotnet test
dotnet run
dotnet run --project src/MyApi

# Pubblicazione
dotnet publish -c Release -o ./publish
# Pubblicazione AOT (C# 12+, .NET 8+)
dotnet publish -c Release -o ./publish /p:PublishAot=true

# Gestione pacchetti (NuGet)
dotnet add package Microsoft.EntityFrameworkCore
dotnet add package Serilog.AspNetCore --version 8.0.0
dotnet list package --outdated
```

### Publish AOT

```bash
# Native AOT compilation: single binary, no JIT, no .NET runtime required
dotnet publish -c Release -r win-x64 --self-contained /p:PublishAot=true
```

Vantaggi: avvio immediato, memoria ridotta, singolo eseguibile. Limitazioni: no reflection dinamica, no generics JIT, no Assembly.Load.

## .NET vs .NET Framework vs .NET Core

| | .NET 8+ | .NET Core 3.1 | .NET Framework 4.8 |
|---|---|---|---|
| Cross-platform | ✅ Sì | ✅ Sì | ❌ Solo Windows |
| Open source | ✅ | ✅ | ❌ |
| Native AOT | ✅ | ❌ | ❌ |
| Windows Forms/WPF | ✅ (solo Win) | ❌ | ✅ |
| Supporto | Corrente | Termine | Manutenzione |

## Modello di progetto

```
MyApi/
├── MyApi.csproj          ← Manifesto del progetto
├── Program.cs            ← Punto di ingresso (top-level statements)
├── Properties/
│   └── launchSettings.json
├── appsettings.json      ← Configurazione
├── appsettings.Development.json
├── Controllers/          ← API controllers
├── Models/               ← DTO / ViewModel
├── Data/                 ← DbContext, migrations
└── Services/             ← Business logic
```

### Formato .csproj (SDK-style)

```xml
<Project Sdk="Microsoft.NET.Sdk.Web">
  <PropertyGroup>
    <TargetFramework>net8.0</TargetFramework>
    <Nullable>enable</Nullable>
    <ImplicitUsings>enable</ImplicitUsings>
  </PropertyGroup>
  <ItemGroup>
    <PackageReference Include="Microsoft.EntityFrameworkCore" Version="8.0.0" />
  </ItemGroup>
</Project>
```

## Ambienti e configurazione

```bash
# File di configurazione
appsettings.json                     ← comune
appsettings.Development.json         ← sviluppo
appsettings.Staging.json             ← staging
appsettings.Production.json          ← produzione

# Variabili d'ambiente (sovrascrivono)
ASPNETCORE_ENVIRONMENT=Development
Db__ConnectionString=...
```
